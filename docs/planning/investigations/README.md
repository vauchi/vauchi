# Investigation Documents

This directory contains problem analysis documents from the first investigation phase.

## Purpose

When a problem is confirmed as valid, an investigation is conducted to:
- Understand the problem deeply
- Identify possible solutions
- Analyze trade-offs

The investigation document captures this analysis and serves as the foundation for solution proposals.

## Naming Convention

`YYYY-MM-DD-<problem-name>.md`

## Template

```markdown
# Investigation: [Problem Name]

## Problem Statement
[Clear description of the problem]

## Context
[Background information, how the problem was discovered]

## Analysis
[Deep dive into the problem]

## Possible Solutions
1. [Solution A] - [Brief description]
2. [Solution B] - [Brief description]
3. [Solution N] - [Brief description]

## Recommendation
[Which solution(s) to evaluate against validation criteria]

## References
- [Links to knowledge documents, if any]
```
