## Directory Structure

```
_docs/
├── INDEX.md              (this file)
├── CLAUDE.md             AI context for this directory
├── architecture/         System design, data models, decisions
├── knowledge/            External research (shared)
├── planning/             Problem records, proposals, retrospectives
│   ├── problems/         Active problem tracking
│   ├── proposals/        Draft plans
│   ├── todo/             Accepted plans in progress
│   ├── done/             Completed (reference)
│   └── archived/         Deferred/rejected
├── deployment/           Infrastructure, production
├── development/          Setup guides, workflows
└── legal/                Compliance, privacy policy
```

## SSOT Markers

Documents use header comments to indicate their role:
- `<!-- SSOT: ... -->` - Single source of truth for a topic
- `<!-- CONDENSED: ... -->` - Summary pointing to authoritative source
- `<!-- REFERENCE: ... -->` - Points to source document

See [CLAUDE.md](../CLAUDE.md) for the full documentation architecture.
